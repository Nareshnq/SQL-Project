# SQL Project — Banking Database

Designed and implemented a robust relational database for a banking system, incorporating Checking and Savings accounts. Utilized SQL to create ER diagrams, enforce primary and foreign key constraints, and manage data types. Integrated advanced features such as error handling, fraud detection, and user authentication to ensure security and reliability.

## What This Project Covers

- **Banking accounts:** Checking and Savings accounts modelled as a relational database.
- **Data integrity:** Primary and foreign key constraints, with appropriate data types for banking data.
- **Database design:** ER diagrams mapping out the relationships between accounts and related entities.
- **Security and reliability:** Error handling, fraud detection, and user authentication.

## How to Use It

1. Open `SQLPROJECT FINAL Query.sql` in SQL Server Management Studio (SSMS) or a compatible SQL editor.
2. Review the script before running it, and run it against a test or development database — not a production database.
3. Use `SQL PPT FINAL.pptx` for a walkthrough of the design and features.
